# 发补智能体 · 可交互原型 v22

医疗器械审评「发补意见」工作台的高保真可交互原型（纯静态，无构建、无后端，数据为演示数据）。

## 在线预览

- 入口：`index.html`（等同任务列表页）
- 页面：任务列表 → 发补智能体（规则校验 / 历史发补分析 / 发补意见草稿）→ 比对智能体 → 申报材料解析 → 法规详情

## 本地查看

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

直接双击 html 也能打开，但建议起本地服务（`file://` 下个别跨页参数会受限）。

## v22 相对 v21 的变化

1. 一键弹出后，剩余列自动填满腾出的空间；新增「收回浮窗」。
2. 系统操作留痕改为一行一条：谁 · 时间 · 做了什么（不再贴「原文 → 新文」）。
3. 规则校验「查看更多」改为页内弹层，不再跳转页面。
4. 规则结果 / 依据 取消模块内滚动，改为平铺；放不下时以规则结果为先，整页滚动。
5. 下线「知识底座」菜单及法规库列表页（法规详情仍可从「依据」进入）。
