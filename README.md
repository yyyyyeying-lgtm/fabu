# 法布 · 发补智能体（原型 v18）

医疗器械注册「发补意见」智能辅助系统的可交互原型。纯前端静态站点，无需后端、无需构建，克隆下来双击 `index.html` 即可运行。

## 页面构成

| 文件 | 模块 | 说明 |
| --- | --- | --- |
| `index.html` | 入口 | 等同任务列表，部署后作为站点首页 |
| `01-任务列表.html` | 审评工作台 | 案卷列表、筛选、新建任务（直接上传文件夹）、四个处理环节的执行状态 |
| `02-发补意见草稿.html` | 发补意见草稿 | 左「问题清单」+ 中「草稿正文」+ 右「申报原文」三栏，支持一键弹出浮窗、上下/左右分屏 |
| `03-历史发补-AI总结.html` | 历史发补分析 | AI 分析、筛选条件、案卷查询结果（可勾选参与分析）、年月日区间 |
| `05-规则校验.html` | 规则校验 | 13 条规则逐条校验、执行进度条、结论采纳、规则依据 |
| `06-法规详情.html` | 法规库 | 法规目录与条文 |
| `07-比对智能体.html` | 比对智能体 | 同品种比对差异清单与原文对照 |
| `08-发补智能体.html` | 发补智能体 | 用 Tab 串联「规则校验 / 历史发补分析 / 发补意见草稿」三个环节 |
| `09-申报材料解析.html` | 申报材料解析 | 上传 → 目录扫描 → ch 文件归类到 RPS 目录（可手动调整）→ PDF 解析 |
| `assets/` | 资源 | `style.css` 样式、`data.js` 演示数据、`app.js` 公共组件、`sum.js` 历史分析、`cascade.js` 级联筛选 |

## 本地运行

方式一（最简单）：双击 `index.html`，用 Chrome / Edge 打开。

方式二（推荐，行为与线上一致）：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> Safari 对内嵌页（`08` 里的 Tab）支持较差，建议 Chrome / Edge。

## 关键业务逻辑

- **问题清单 = 三来源汇总**：规则校验、比对智能体、历史发补推送来的条目，按 **ch 文件名称自动归并**为同一个问题，子项按推送时间顺延、重新编号（一）（二）（三）。
- **依据跳转**：草稿里每个问题 / 子项带「规则依据」，按来源分别跳到规则校验的当条规则、比对智能体的该条差异、历史发补的该条参考。
- **只分析勾选的案卷**：历史发补分析的结果列表可勾选，「按当前筛选条件生成 AI 分析」只对勾选的案卷生效。
- **归类可人工干预**：ch 文件按文件名自动挂到 RPS 目录，支持行内下拉、拖拽、批量归入三种方式调整。

## 部署

静态站点，Vercel 零配置：

```bash
vercel deploy --prod --yes
```

`index.html` 会自动作为首页；页面间跳转使用相对路径，无需额外路由配置。
